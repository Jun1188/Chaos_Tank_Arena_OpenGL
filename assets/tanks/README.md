# Sand tank 연결

- 원본: 사용자가 제공한 `sand-tank.glb`. 파일을 변환하지 않고 이 폴더에 복사했다.
- 좌표: Y-up, 전방 -Z. `Hull` 아래 궤도 2개·바퀴 12개·`Turret`, `Turret` 아래 `Barrel`.
- 현재 연결: `game::TankEntity` → `PreviewFrame::tanks` → `tmpBoxing::SandTankModel`.
- GLB 노드의 로컬 정점·변환과 재질 기본색을 Assimp로 읽고 기존 프레임워크 `Mesh`로 그린다. 외부 라이브러리는 추가하지 않았다.
- 포탑 Y 회전과 포신 X 회전은 기존 `TankPose`를 사용한다. 포탑 장착점 `(0, 0.79, 0.29)`, 포신 힌지 `(0, 0.32, -0.86)`는 GLB 노드 값이다.
- `makeSandTankSpec()`의 충돌 상자는 부품 정점 경계를 감싸는 근사 OBB다. 차체 OBB는 고정 궤도를 포함한다. 정밀 매시 충돌은 사용하지 않는다.
- 포구는 포신 로컬 `(0, 0, -2.01)`이다. 포신 끝 `z=-2.0`에서 0.01만큼 앞에 둔다.
- 바퀴 반지름 0.176, 좌우 축 간격의 절반 0.813. 실제 전후 이동과 차체 회전으로 좌우 회전각을 계산한다. 궤도는 차체에 고정한다.
- 플레이어는 원래 재질색을 표시한다. 표적은 기존 체력별 색을 재질에 곱한다. 재질색·노멀과 간단한 방향광을 사용하며 PBR 전체를 재현하지 않는다.
- 텍스트는 UTF-8 BOM으로 저장했다. 전용 셰이더 로더는 소스를 OpenGL에 전달할 때 BOM 3바이트를 건너뛴다.
- GLB 또는 전용 셰이더를 읽거나 컴파일하지 못하면 기존 박스 탱크를 표시하고 콘솔에 원인을 남긴다. F1 충돌 상자와 포구 축은 유지한다.
- 기존 `TankSpec` 기본값은 박스 프리뷰 호환용으로 보존했다. 현재 장면의 두 탱크는 `makeSandTankSpec()`을 사용한다.
- 이 어댑터는 제공된 rigid GLB용이다. 본·스킨·클립·텍스처 애니메이션은 처리하지 않는다. 정식 렌더 모듈 통합은 별도 작업이다.

## 사용자가 수행할 확인

빌드와 실행 테스트는 수행하지 않았다. Visual Studio에서 빌드 후 다음을 확인한다.

1. 실행 시 콘솔에 `Tank GLB ready`가 나오고, 플레이어와 표적에 탱크 매시가 표시되는지 확인한다.
2. F1으로 디버그 표시를 끈다. WASD로 전진·후진·제자리 회전한다. 바퀴는 축 중심에서 돌고 궤도는 차체에 고정되어야 한다.
3. 방향키 또는 마우스로 조준한다. 포탑은 Y축, 포신은 힌지 X축으로 돌고 포신은 포탑을 따라야 한다.
4. F1으로 충돌 상자를 표시한다. 좌클릭으로 발사한다. 탄은 포구 앞에서 출발하고 표적에 맞으면 HP가 감소해야 한다.
5. R로 초기화한다. 탱크 자세와 바퀴 회전각이 초기화되어야 한다.
6. 빌드 결과 폴더를 작업 디렉터리로 실행할 때도 저장소 안의 GLB와 셰이더를 찾는지 확인한다. 리소스는 실행 파일 옆으로 자동 복사하지 않는다.
